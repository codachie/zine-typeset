ZINE 組版プレビュー

プロトタイプ / 開発中 Google ドキュメント・Word の原稿を、縦書き右開き／横書き左開きでプレビュー

アップロードした原稿は あなたのブラウザの中だけ で処理されます。サーバーには送信されず、どこにも保存されません。 ページを閉じればデータは消えます。

原稿

Word（.docx）／ テキスト（.txt・.md）を選択。Google ドキュメントは 「ファイル → ダウンロード → Microsoft Word (.docx)」で書き出し。

メモ / Evernote などの文章を貼り付ける

行頭の記号で指定できます：
@ 書名／@@ 副題 … 扉に表示
# 章タイトル … 章（## で小見出し）。「第一章」「はじめに」等は記号なしでも章に
記号が無ければ、1行目も本文扱い・目次なしの通し組みでプレビューします。

画像（別丁：1ページ丸ごと）

ページ番号を指定して画像を差し込みます。指定ページ「あたり」に入ります（本文を増減すると多少ずれるので、必要なら番号を微調整）。 白黒／カラー・幅（%）・天地の配置を画像ごとに設定できます。画像はブラウザ内だけで扱われ、外部に送信されません。
※ 画像を入れると位置計算のため組版を2回行うので、更新に少し時間がかかります。
